### Off the Clock: source code of our game mods

**Free mods for PC games, with the source open so you can read exactly what runs on your machine.**

Every repository here holds the code, tests and build files for the mods we publish for one game. All of it is MIT licensed. The mods themselves are free; download them from the places players use:

- **All our mods, by game:** [mods.offtheclocksoftware.com](https://mods.offtheclocksoftware.com/)
- [Nexus Mods](https://www.nexusmods.com/profile/offtheclock), plus Steam Workshop (per-mod links are on that list)
- [Thunderstore](https://thunderstore.io/c/riskofrain2/p/OffTheClock/) for Risk of Rain 2

**How we make mods**

- Single-player and co-op only. Nothing touches other players, online modes or leaderboards.
- Settings start at the game's own values; each mod page says plainly what it changes, including saves and achievements.
- Every release passes automated checks (a linter and an offline test harness) and an unattended in-game run before it goes up.
- We build with AI-assisted tools, and every release is tested before publishing.

Found a bug? Please report it on the mod's page (Nexus Mods or Thunderstore) with your game version and what you did just before it happened; that is where we answer fastest.
